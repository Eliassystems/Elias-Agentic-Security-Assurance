## Git byte-preservation control

Publication pre-flight identified a transport-integrity issue caused by the repository Git configuration.

With core.autocrlf=true and no applicable repository .gitattributes rule, Git filtered-byte simulation produced byte mismatches for 43 of the 45 publication files then present.

To prevent Git from silently normalizing evidence bytes during staging or commit, this publication successor includes a package-local:

.gitattributes

with:

* -text
**/* -text

After adding that control, Git filtered-byte simulation across all 46 publication files produced zero hash mismatches.

The same rule applies to the future active SHA256SUMS.txt and SHA256SUMS.sha256 paths.

This is a publication transport-integrity control only.
